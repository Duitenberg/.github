# Duitenberg Quantitative Finance

We are Duitenberg's quantitative finance committee. We bring together members interested in markets, data, mathematics and software.

We build tools for investment research, test quantitative ideas and work on projects together. The aim is to understand what works, where it breaks and what the evidence supports.

This GitHub organization is the home for our shared code and project work. Experience levels vary; research, analysis, code and careful review all have a place here.

New here? Start with the [onboarding guide](https://github.com/Duitenberg/onboarding).
